# Nodalia Guardian visual identity

The Guardian GitHub App must display the **exact owner-supplied Nodalia logo**.
GitHub hosts the App avatar; its official upload path is documented in
[`docs/github-app-setup.md`](../docs/github-app-setup.md).

Do not substitute a generated picture or the logo of another Nodalia app.
The image provided in chat is a design reference; the **original binary image** must
be saved here as `assets/nodalia-guardian-avatar.png` once made available as a file.
No image is included in this repository snapshot, and no avatar has yet been configured
on a live GitHub App.
